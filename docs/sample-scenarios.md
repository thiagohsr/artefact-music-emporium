# Sample Scenarios

Questions to try in the chat, taken from the challenge brief. Each one exercises a different part of the agent.

| Message | What it exercises |
|---|---|
| Quais opções de violões disponíveis custando até R$1000? | Catalog search with a price limit |
| Qual o endereço da loja? | General store information |
| Quanto custa o Takamine GD20? | A product's price |
| Me arrependi da minha compra, posso devolver meu pedido? | Applying the return policy |

Start the chat with `make run-dev` to see which tools and sources produced each reply.
