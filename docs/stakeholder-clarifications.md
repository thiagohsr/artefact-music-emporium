# Stakeholder Clarifications

Conflicts found in the store manual (`data/políticas_da_loja.pdf`, version 2.1), the rule the agent
follows until each is settled, and what the store needs to confirm.

| # | Topic | Working rule | Status |
|---|---|---|---|
| 1 | WhatsApp number | Give both numbers as alternatives | Needs confirmation |
| 2 | Email address | Use `contato@emporiodamusica.com.br` | Decided |
| 3 | Credit card installments | Use the tiered minimums from section 3.1 | Needs confirmation |

## 1. WhatsApp number

**Conflict**: section 1.2 lists (67) 3341-4444 as "Telefone / WhatsApp", while section 7 says the
WhatsApp channel is (67) 3321-4500.

**Working rule**: when a customer needs WhatsApp, the agent gives both numbers and suggests trying
the other if one does not answer.

**Question for the store**: which number is the current WhatsApp channel, and does the other one
still receive messages?

## 2. Email address

**Conflict**: the cover has `contato@emporiodamusica.com.br`, while section 1.2 has
`contato@empóriodamusica.com.br`, with an accent.

**Working rule**: the agent always uses `contato@emporiodamusica.com.br`, the version without the
accent, and never mentions the other one.

## 3. Credit card installments

**Conflict**: the payment table in section 3 sets a R$ 100.00 minimum per installment for up to 12x.
Section 3.1 sets lower minimums for shorter plans, and its wording for plans up to 3x contradicts
itself: "no minimum installment value (except below R$ 50.00)".

**Working rule**: all plans are interest-free, and the agent offers the longest plan whose
installment meets the minimum:

| Plan | Minimum per installment |
|---|---|
| Up to 3x | R$ 50.00 |
| 4x to 6x | R$ 80.00 |
| 7x to 12x | R$ 100.00 |

**Why this rule**: section 3.1 is the dedicated, more detailed installment rule, and it gives more
payment options on entry-level instruments, which fits the store's mission of broadening access. The
"up to 3x" exception is read as a R$ 50.00 minimum.

**Impact**: at current list prices, the rules give different results for 16 of the 65 products, all
priced at R$ 599.90 or less. Promotional prices may change these results.

| Product | Price | Table rule | Working rule |
|---|---|---|---|
| Shelby SU-21S Soprano Sunburst | R$ 159.90 | 1x | 3x |
| Ohana SK-10 Soprano Natural | R$ 249.90 | 2x | 3x |
| Yamaha C40 Nylon Natural | R$ 599.90 | 5x | 6x |

**Risk**: if the R$ 100.00 table is the correct rule, the agent would offer those 16 products one or
two more installments than the store allows.

**Questions for the store**:

1. Which rule applies: the single R$ 100.00 minimum or the tiered minimums?
2. For plans up to 3x, is R$ 50.00 the minimum per installment?
